# NEON VAULT

白・ピンク・ベージュ・金を基調にした、ブラウザで遊べる召喚・育成ゲーム。
ゲーム内コインのみ使用し、課金・換金はありません。

## 遊ぶ

https://usaginchaku.github.io/neon-vault/

- **ホーム**：お気に入り・所持通貨・探索ボタンを一画面に表示。「変更」でキャラを選択。ログインボーナスは右上のギフトから開きます。
- **ログインボーナス**：日本時間0時更新、1日1回。累計7日で一巡し、休んだ日があってもリセットされません。
- **召喚**：3地域、46種類。1回300 / 10回2,700コイン。SSR・URは短い特別演出付き。
- **育成**：3体を編成、育成石でLv.30まで。重複1体ごとに突破し最大6突破。3突破でスキル強化、6突破で再使用短縮。
- **探索**：五行の相性を使うターン制戦闘。攻撃・スキル・防御を選択。3地域各10層、HP持越し、休憩2回。帰還で報酬を全額獲得、敗北時は探索中コインの75%と育成石を獲得。
- **周回**：クリア済みの階層を1・5・10回。毎戦HP全回復、途中停止可能。時間回復スタミナはありません。
- **スロット**：100 / 300 / 1,000コインをベット。5絵柄、3一致で4〜30倍、2一致でベット返却。

通常排出率はR65% / SR25% / SSR7% / UR3%。同レアリティ・同地域内は均等。
10連でSR以上1体確定。SSR以上が出ず19回の次はSSR以上確定、URが出ず59回の次はUR確定。
保証カウントは全地域で共通。相剋はダメージ+35%、相生の順で攻撃・スキルをつなぐとダメージ・回復+15%。
四神は青龍（木）・朱雀（火）・白虎（金）・玄武（水）。

## iPhoneのホーム画面に追加

Safariでゲームを開き、共有 →「ホーム画面に追加」→「追加」。
対応iOSでは「Webアプリとして開く」をオンにします。専用の180pxアイコン、Web App Manifest、セーフエリア、オフライン起動に対応しています。

セーブは端末・ブラウザ・公開先ごとのlocalStorageです。サイト間・端末間の自動同期はありません。
移行時は **設定 → セーブデータ → 書き出す** を使い、移行先で **設定 → セーブデータ → ファイルを選択** から読み込みます。
旧版の獲得数・レベル・コインを引き継ぎ、旧データのバックアップも端末内に保存します。
ログイン判定は端末時計を使います。アカウント認証・オンライン対戦・SNS投稿機能はありません。

## 開発

ビルド不要。Node.js 22以上。`dist/`を静的配信します。

```sh
npm start
npm test
```

SVGとオフラインキャッシュを再生成する場合：

```sh
npm run generate
```

ブラウザの操作検証にはPlaywrightとChromiumが必要です。`NEON_TEST_URL`と`CHROMIUM_PATH`で指定できます。

```sh
NEON_TEST_URL=http://127.0.0.1:3000 npm run test:browser
```

- `dist/data.js`：キャラクター、五行、地域、スロット絵柄
- `dist/engine.js`：召喚、育成、戦闘、報酬、保存
- `dist/app.js`：ホーム、各画面、操作、演出
- `scripts/create-art.mjs`：元の幾何学モデルの明るい配色と装備差分
- `scripts/create-pwa.mjs`：アイコンSVG、Manifest、キャッシュ一覧
- `tests/engine.test.mjs`：確率、保証、移行、戦闘、精算、日付境界
- `tests/browser-smoke.cjs`：操作、スマホ表示、オフライン起動

GitHub Pagesは`.github/workflows/pages.yml`で`main`更新時に自動公開します。
英字フォント（Barlow Condensed / DM Sans）はライセンスと共に同梱。SVGはこのゲーム用の図形です。外部画像生成・外部API通信は使用しません。
